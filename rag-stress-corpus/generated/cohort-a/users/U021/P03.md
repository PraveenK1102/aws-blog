## The design

One badly scoped timeout propagated into three services before anyone noticed. Because a timeout longer than the caller's is not a timeout but a leak, we shortened it deliberately. When I finally measured it, transactions was 45% change.

We added one metric, waited a week, and the cause became embarrassingly clear. Because the consumer fell behind quietly, the first symptom was a customer report. Nobody had rehearsed the rollback, so we rehearsed it afterwards and wrote it down. I no longer trust a health check that only proves the process is running.
